# Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Description

This is a classic two-player Tic Tac Toe game where players take turns marking spaces in a 3×3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.

## Features

- Two-player gameplay (Player O and Player X)
- Winner detection for all winning patterns
- Reset game functionality
- Start new game after a win
- Clean and responsive user interface
- Visual feedback with modal message for winners

## How to Play

1. Open `index.html` in your web browser
2. Player O goes first
3. Click on any empty box to place your mark
4. Players alternate turns between O and X
5. The first player to get three marks in a row (horizontally, vertically, or diagonally) wins
6. Click "Reset Game" to clear the board and start over
7. After a win, click "Start New Game" to play again
